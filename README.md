# CYNEX Agent Studio (CYNEX AI AGENT STUDIO)

**ARC, NVIDIA GPU PC를 위한 올인원 로컬 AI 에이전트 스튜디오**입니다.
설치 한 번으로 내 PC 안에 AI 에이전트 환경(로컬 LLM · 이미지/영상 생성 · 문서 작업)을
자동 구성하고, 채팅 한 줄로 **웹페이지 제작 · 보고서 작성 · 이미지/영상 생성 · 
간단한 게임 개발**까지 시키는 데스크탑 앱입니다.

> 이 저장소는 **실행 파일 배포용**입니다. 모든 AI 추론은 사용자 PC의 GPU에서
> **로컬로** 동작하며, 별도 구독료나 API 비용이 없습니다. 대화·문서·생성물은 PC 밖으로
> 나가지 않습니다.

## 🚀 설치 방법

1. 위에서 **CYNEX-Agent-Studio.exe** 를 다운로드합니다.
   브라우저가 *"일반적으로 다운로드되지 않는 파일"* 안내를 표시하면 **[유지]** 를 선택하세요.
2. 다운로드한 exe 를 실행합니다.
3. *"Windows의 PC 보호"* (SmartScreen) 경고가 나오면 **[추가 정보] → [실행]** 을 클릭하세요.
   (무료 배포 프로그램으로 코드 서명 인증서를 사용하지 않아 표시되는 안내입니다.)
   *"스마트 앱 컨트롤이 안전하지 않을 수 있는 앱을 차단했습니다"* 가 나오면 아래
   **🛡️ 스마트 앱 컨트롤에 막힐 때** 항목을 따라 주세요.
4. 첫 실행 시 **사용 안내와 오픈소스 고지**를 읽고 동의합니다.
5. **셋업** 화면에서 자동 설치를 진행하면 HERMES 에이전트 · llama.cpp · ComfyUI ·
   LibreOffice · AI 모델이 순서대로 구성됩니다.
   ⏱ 첫 설치는 인터넷 속도에 따라 **1시간 이상** 걸립니다. 설치 중 PC를 끄지 마세요.
6. 설치가 끝나면 왼쪽 메뉴에서 **CYNEX HERMES** 를 열고 대화를 시작하세요.

## 🛡️ 스마트 앱 컨트롤에 막힐 때

새로 산 PC 나 윈도우를 새로 설치한 PC 에서는 Windows 11 의 **스마트 앱 컨트롤**이 켜져 있어,
실행하자마자 *"스마트 앱 컨트롤이 안전하지 않을 수 있는 앱을 차단했습니다"* 창이 뜰 수 있습니다.
코드 서명 인증서가 없는 프로그램을 막는 기능이며, 이 기능에는 **프로그램별 예외가 없어**
기능을 꺼야 실행할 수 있습니다.

1. **[시작] → [설정]** 을 엽니다.
2. **[개인 정보 및 보안] → [Windows 보안] → [앱 및 브라우저 컨트롤]** 로 갑니다.
3. **[스마트 앱 컨트롤 설정]** 을 누르고 **[끄기]** 를 고릅니다.
4. 확인 창이 나오면 **[예]** 를 누른 뒤, CYNEX-Agent-Studio.exe 를 다시 실행합니다.

- 스마트 앱 컨트롤이 켜져 있는 동안에는 실행할 때마다 다시 막힙니다. 설치 중에 받는 구성요소
  (LLM 실행 서버 등)도 막힐 수 있으므로, 이 프로그램을 쓰는 동안은 꺼 두어야 합니다.
- 2026년 4월 이후 업데이트(KB5083769)를 받은 PC 는 같은 화면에서 다시 켤 수 있습니다.
  그보다 오래된 PC 는 한 번 끄면 윈도우를 다시 설치해야 다시 켜집니다.
- 회사에서 관리하는 PC 는 이 설정이 잠겨 있을 수 있습니다. 그때는 PC 관리자에게 문의하세요.
- 끌지 말지는 PC 사용자가 판단할 일입니다. 백신(Microsoft Defender 등)은 그대로 켜 두셔도 됩니다.

## ❓ 자주 묻는 질문

- **설치가 멈춘 것 같아요** — 대용량 모델 다운로드 구간은 진행이 느려 보일 수 있습니다.
  셋업 화면의 로그에서 진행 상황을 확인하세요.
- **답변 속도를 더 빠르게 하고 싶어요** — 채팅 입력창의 생각 깊이를 **Low** 로 낮추면 빨라집니다
  (기본은 Medium). 대화가 아주 길어지면 느려지므로, 새 작업은 새 대화에서 시작하는 편이 빠릅니다.
- **이미지 생성 중에 채팅이 잠시 느려져요** — 한 GPU 를 나눠 쓰는 동안의 정상 동작입니다.
  생성이 끝나면 자동으로 복원됩니다.
- **인터넷이 끊겨도 되나요?** — 처음 실행시 온라인 상태로 자동 로그인되어야하며 이후에는 오프라인에서도 대부분의 기능이 동작합니다
  (웹 검색·웹 자료 조사 제외).
